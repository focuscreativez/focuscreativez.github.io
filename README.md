# Focus Creativez — David Opara

Static film and photography portfolio prepared for GitHub Pages.

## Publish
Create a public repository named `focuscreativez` and upload these files to the `main` branch with `index.html` at the repository root. In repository Settings → Pages, select Deploy from a branch, `main`, and `/(root)`, then Save. GitHub displays the final Pages address when deployment is complete.

All local asset paths are relative so the website works under a project path as well as a custom domain. No build step or npm dependencies are required. `.nojekyll` preserves this as a plain static website.
